# Chau's Reading Lab

Web luyện Reading tiếng Anh. *Designed by Le Bao Chau.*

- `index.html`: giao diện (trang chủ, làm bài, kết quả, ôn từ vựng)
- `tests.js`: ngân hàng bài. Thứ tự trong file = thứ tự trên trang chủ.
  - `group`: nhóm hiện trên trang chủ
  - `hidden: true`: ẩn bài khỏi trang chủ (vẫn mở được bằng link `#MÃBÀI`)
